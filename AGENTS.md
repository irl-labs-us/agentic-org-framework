# Agent instructions for this repo

If the user asks to set up, adopt, or configure the Agentic Organization Framework for their project — or opens this repo after using it as a GitHub template — read `SETUP.md` and follow it exactly: interview the user one section at a time, don't skip ahead, and write the resulting files to the paths it specifies.

For everything else (questions about the framework itself, editing `FRAMEWORK.md`, reviewing the governance scripts), `README.md` is the map of what's in this repo.
